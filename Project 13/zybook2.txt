19.4 INSERTION SORT
- Insertion sort is a sorting algoritm that treats the input as two parts, a sorted part and an unsorted part, and repeatedly inserts the next value from the unsorted part into the correct location in the sorted part
- In the worst case, assuming each comparison takes 1 µs, how long will insertion sort algorithm take to sort a list of 10 elements?

- Because a constact list is sorted, a faster search, known as a binary search, checks the middle contact first.
- If the desired contact comes alphabetically before the middle contact, binary seach will then search the first half and otherwise the last half.- Each step reduces the contacts that need to be searched by half.

- Binary Search is a faster algorithm for searching a list if the list's elements are sorted and directly accessible (such as an array)
- Binary search first checks the middle element of the list. 
- If the search key is found, the algorithm returns the matching location
- If the search key is not found, the algorithm repeats the search on the remianing left sublist ( if the seach key was less than the middle element) or the remianing right sublist (if the seach key was greater than the middle element)
